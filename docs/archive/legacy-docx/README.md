# Pachi — Historical Source Policy

> **Status:** Accepted implementation baseline  
> **Baseline:** Pachi 2.1  
> **Updated:** 2026-09-24  
> Acceptance establishes the design to implement; it does not certify implementation, testing, vendor readiness, or launch readiness.

This directory documents the status of old DOCX/SQL/design artifacts. The canonical product and engineering rules are the Markdown files linked from [the documentation index](../../README.md).

The [pre-reconciliation source snapshot](../pre-reconciliation-sources.zip) contains the supplied document versions/package and the earlier V2 product/domain text used for comparison. It is historical evidence, not an implementation input. The supplied standalone files and ZIP differed; reconciliation resolves both into one current package.

Actual DOCX binaries or old schema files already in the repository should be retained under the repository archive with clear noncanonical labels where appropriate. This delivery does not claim to have moved files in the user's local repository. No archived SQL has been executed or certified compatible with baseline 2.1.

Do not modify archived files to make them look as if they always reflected current decisions. Apply new changes to the canonical Markdown and record the reason in version history.
